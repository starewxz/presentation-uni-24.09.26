# 🏛️ Університетська інтерактивна презентація: «Віхи політичної історії про гуптів»

> **Джерельна основа:** Крижанівський О. П. *«Історія Стародавнього Сходу: Підручник»*. — К.: Либідь, 2000 (Розділ «Імперія Гуптів», с. 396–412).  
> **Стек технологій:** React 19, Vite, Tailwind CSS, Lucide Icons, GitHub Pages.

---

## 📖 Що входить у проєкт?

1. **[SPEECH_TEXT.md](./SPEECH_TEXT.md)** — **Повний текст промови доповідача** (регламент: **рівно 10 хвилин**):
   - Вступне слово та аргументація актуальності теми.
   - Послайдовий розгорнутий текст із науковими цитатами, риторичними зв'язками та акцентами за О. П. Крижанівським.
   - Спеціальний розділ: **Шпаргалка відповідей на типові запитання викладача (Q&A)**.
2. **Інтерактивна React-презентація (10 слайдів / ~10 хв)**:
   - **Мінімум тексту на слайдах:** Лише ключові смислові картки, цифри, періодизація та порівняльні таблиці.
   - **Автентичні історичні артефакти:** Справжні монети Чандрагупти I, Самудрагупти з віною, Чандрагупти II, Залізна колона в Делі, руїни Наланди, шедеври скульптури Сарнатха та фрески Аджанти.
   - **Режим доповідача (`N`):** Інтегрована висувна панель із промовою для кожного слайду, таймером і підказками щодо вимови санскритських назв.
   - **Шпаргалка Q&A (`Q`):** Готові відповіді на складні семінарські запитання.
   - **Огляд усіх слайдів (`O`):** Можливість миттєво перейти до будь-якого слайду.
   - **Повноекранний режим (`F`):** Презентація розгортається на весь екран як професійний слайд-дек.

## 🌐 Як БЕЗКОШТОВНО захостити на GitHub Pages?

Проєкт уже налаштований для безкоштовного розміщення без додаткових серверів!

### Варіант А (Автоматичний через GitHub Actions — найпростіший):
1. Створіть новий репозиторій на [GitHub](https://github.com/new).
2. Завантажте цей проєкт у ваш репозиторій:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Gupta empire presentation"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГІН/ВАШ_РЕПОЗИТОРІЙ.git
   git push -u origin main
   ```
3. На сторінці вашого репозиторію на GitHub перейдіть у **Settings** ➔ **Pages** ➔ у графі **Source** оберіть **GitHub Actions**.
4. Готово! Презентація збереться автоматично і буде доступна за адресою:
   `https://ВАШ_ЛОГІН.github.io/ВАШ_РЕПОЗИТОРІЙ/`

### Варіант Б (Через команду `npm run deploy`):
1. У файлі `package.json` змініть поле `"homepage"` на адресу вашого сайту:
   `"homepage": "https://ВАШ_ЛОГІН.github.io/ВАШ_РЕПОЗИТОРІЙ"`
2. Виконайте команду:
   ```bash
   npm run deploy
   ```
   Скрипт автоматично створить гілку `gh-pages` і опублікує сайт!

## ⌨️ Керування презентацією під час виступу:

| Клавіша | Дія |
| :--- | :--- |
| **`→`** / **`Пробіл`** / **`PageDown`** | Наступний слайд |
| **`←`** / **`PageUp`** / **`Backspace`** | Попередній слайд |
| **`N`** (або укр. **`Т`**) | Відкрити/сховати **Нотатки доповідача** з повною промовою |
| **`O`** (або укр. **`Щ`**) | **Огляд усіх слайдів** (швидкий перехід) |
| **`Q`** (або укр. **`Й`**) | **Шпаргалка відповідей на запитання викладача (Q&A)** |
| **`F`** (або укр. **`А`**) | Увімкнути/вимкнути **Повноекранний режим** |
| **`Home`** / **`End`** | Перехід до першого / останнього слайду |
| **`Esc`** | Закрити активне модальне вікно або панель |
| **Клік по фото** | Збільшити артефакт у високій роздільності для демонстрації |

## 📚 Структура 10 слайдів (таймінг: 10 хвилин):

1. **Титульний слайд:** Віхи політичної історії про гуптів (~0:45 хв).
2. **Передумови:** Політична дезінтеграція Північної Індії та вихід роду Гуптів (~0:55 хв).
3. **Чандрагупта I:** Династичний шлюб із Ліччхавами, статус Махараджадхіраджа та Ера Гуптів (~1:00 хв).
4. **Самудрагупта:** «Індійський Наполеон», Аллахабадський напис Харішени та ритуал Ашвамедха (~1:00 хв).
5. **Стратегія завоювань:** Дві моделі — анексія Півночі («учитпада») та васалітет Півдня («грахана-мокша») (~1:00 хв).
6. **Чандрагупта II Вікрамадітья:** Розгром саків, записки Фасяня та феномен Залізної колони в Делі (~1:10 хв).
7. **Політико-адміністративна анатомія:** Бхукті, Вішая, Грама, купецькі міські ради та саманти (~1:00 хв).
8. **Кумарагупта I:** «Сорок років миру» та перший міжнародний університет у Наланді (~0:55 хв).
9. **Оборона та крах:** Скандагупта, битва з білими гунами, виснаження казни та розпад імперії 550 р. (~1:10 хв).
10. **Цивілізаційна спадщина:** Класичний індуїзм, математика Аріабхати, драми Калідаси та печери Аджанти (~1:05 хв).
